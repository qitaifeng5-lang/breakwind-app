# 饮食质量整改 · 2026-11-14

基线96c2316，沿用PR #13。训练课程参数、长期周期、会员测试价格未修改。以下是运行实现及数据边界，不是全面中国市场覆盖声明。

## 正式流程

首页改为紧凑营养概览、四餐、单一添加入口、最近与常用组合。搜索和份量采用正式全屏页面，餐次快速切换，最近搜索留在本机，返回保留关键词和列表位置。保存返回原餐次，修改/删除立即更新合计。缺项显示未记录。组合持久化、备份兼容；复制昨日使用历史快照并按来源记录去重。
