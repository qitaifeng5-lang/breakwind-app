# 首发：训练计划与饮食记录

本轮沿用 PR #13 分支与全屏阅读页面，不更改课程剂量、免费课程质量或 VIP ¥12.9/月测试方案，不启用收款。

## 可用流程

训练 → 选择课程 → 加入课表 → 查看课表 → 改期／改时 → 记录完成、部分完成或未完成。完整周草案、教练原文、固定时段、日程例外和长期计划保留。过去日期不自动完成，漏课不自动补排；长期复盘区分本人反馈、旧完成标记、未知、关联运动历史。安全保护依然生效。

饮食 → 添加餐次 → 搜索食物 → 调整份量 → 保存。最近、收藏、组合餐、汇总与历史保留；未接通的拍照与扫码不提供入口；不扣减未测的运动消耗。

右上角个人与设置提供资料、备份合并、导出、历史运动和旧草稿。合并不覆盖同 ID 原记录，保留收藏、固定时段和伤痛暂停；已有个人设置仅补缺。会员状态不会由备份提升。旧草稿可冻结后归档／导出，不能开启新追踪。

## iOS 安装准备与边界

原有 Expo 项目入口现加载由正式网页源码生成的离线界面，并通过桥接将本机数据串行保存到 SQLite；不是远程网页地址。系统分享用于导出。旧 `breakwind-runs.db` 原样保留，启动／返回前台时清理已注册的旧定位任务，短草稿也能保留原始采样。定位、运动与 HealthKit 权限描述、后台模式和 entitlement 从最终 iOS 配置移除。定位库仅保留升级清理用途，没有新的启动或权限请求。

开发机准备：`npm ci`，`npm run check:ios`，`npm run mobile:bundle -- --max-workers 2`。macOS/Xcode 连接 iPhone 后执行 `npm run mobile:ios`；脚本先生成与当前提交相同的离线界面。现有 bundle ID `com.breakwind.running.dev` 保持不变，便于升级数据验收。

正式安装与发布还需：Apple 开发者团队签名、Mac/Xcode、真实 iPhone；核实正式 bundle ID 与开发版本的迁移策略后再申请发布。未建立付费 EAS 构建，未上传 App Store 或开启收费。Hermes 构建包不是可安装 IPA。

真机验收必须覆盖：旧版本升级后停止定位且不弹定位权限；飞行模式看课表与记录餐食；强退再开保留修改；系统文件导入／分享；大字体、键盘、安全区；旧数据库历史及草稿归档；同名课表和长期计划不被自动覆盖。浏览器内嵌页面契约测试不代表这些真机项目通过。

## 质量与内容状态

来源核验、产品编排、独立教练审核、可执行状态保持分开。尚未独立审核的课程仍明确标记；移除播放器不意味着放行不适用课程。没有更改历史课次处方或把课程估算写成实际运动。
