# 教练课表优先：交付边界

## 已接入正式页面
- 已有当前教练课次时显示「我的课表」，无课次时显示原课程库。课程库保持辅助入口。
- 单节手动录入／粘贴 → 四段核对 → 确认保存。原文、用户确认的转录与实际运动记录分别保存；取消预览不写入。
- 确定性解析只识别显式四段标签（含趟间／组间恢复），其他文字原样保留。未归类、缺失目标和待补参数突出提示，不生成配速、次数或恢复。
- 资料来源由用户声明，平台未验证其教练身份。历史参考不能通过开始按钮转为当前执行；也不自动生成实际运动。
- 固定俱乐部、学习和工作时段可复用；未来七天可设单次取消／改时／改期。例外覆盖原固定安排，下一周继续原规则。
- 日期明确的课次可替换本日固定训练槽。改期保留原槽的例外关联，不重复生成原课；重新检查目的日期占用及相邻质量课。
- 准备、完整课次预计时长、缓冲组成估计占用。完整课次时长需包含热身、主训练、全部恢复及冷身；未知则不显示精确结束时间。不会压缩恢复来处理冲突。
- 同期教练课次阻止课程库质量课额外叠加。已知伤痛保护保留，青少年显示适龄核对提示。

## 私有数据与限制
原文与个人时间仅进入当前浏览器的本地存储，不调用模型、不发送到服务器，也不纳入公共课程库。浏览器存储不是加密保险库，清理浏览器会丢失记录；使用现有备份功能自行保管。仅用明确标注的合成数据测试，没有连接或读取真实教练邮箱、历史团队原文，不能声称真实课表已经导入。

当前输入单位为一节课；未实现任意多周自然语言自动拆课，也未把含糊原文编译成自动分段计时。现有课程库分段执行、独立 GPS／手动运动记录均保留。导入课次仅作安排和核对，实际完成必须另行记录；不以计划参数填充实际运动。相邻负荷检查采用保守提示，不构成个体训练适用性判定。独立教练审核和真实 iPhone 验收尚未完成。

## 验证
纯函数检查原文保真、缺失不猜、占用时间、冲突阻止改期、无重复、例外覆盖、历史不变和存储恢复。浏览器检查预览取消不保存、确认保存、刷新恢复、详情一致、改时写入。首次浏览器测试发现隐藏字段 `name=id` 遮蔽表单属性，已改为 `planId` 后复测。
部署验证脚本检查提交元信息与本地导出资源字节相同，采集正式页面截图和录屏。证据使用合成 Tempo，不是教练处方，也不作为新的课程推荐。
