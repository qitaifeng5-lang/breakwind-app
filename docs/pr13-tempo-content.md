# PR #13：分段Tempo编排与周草案状态（评论6754623914）

## 实际交付

在原Tempo条目中完成一节「分段Tempo · 3×5分钟」，没有扩大课程数量或重做四段式界面。

- 目的：基础期积累受控有氧工作，短恢复后重新稳定节奏。不是800m/1500m比赛节奏，也不是精英常规阈值主课。
- 适用：成人基础/进阶中跑组，有持续有氧训练并已有累计15分钟同类Tempo耐受。竞技组仅限基础期低总量衔接。首次Tempo、近期中断或恢复不足不直接执行。PB不能确认这些条件；浏览不需设备日志。
- 完整结构：热身10分钟（轻松活动、动态准备、渐进准备检查；准备不足继续）→1大组、3趟×5分钟Tempo→两次趟间60秒轻松慢跑→冷身10分钟。无组间恢复、无最后一趟后的额外恢复。
- 强度：已有Tempo体感，受控偏强、呼吸和动作稳定；不末段加速。不能维持则降速、延长实际恢复或提前结束，不强求完成。体感不是乳酸测量，不能从800m/1500m PB推算阈值秒数。
- 核算：主训练900秒，恢复120秒，热身冷身1200秒，计划全程2220秒（37分钟）；实际耗时单独记录。距离未测量，主训练总距离为未知，不按PB补算。
- 实现：完整时长课程可直接进入现有热身/分段/恢复/冷身记录，不要求用户设计次数和恢复。未满设定时间不能算完成一段，但可提前结束。旧课次快照不被新模板替换。

## 分组周方案推进边界

界面改称「周安排草案」。成年人的基础期明确填入本轮Tempo主课；专项期分别填入已有800m或1500m完整间歇候选。属于有条件编排位置，不自动推荐、不一键执行，不根据更快PB增加主课。低强度日与适龄方案仍有缺口，因此两专项均不能称为完整周课表。来源已核对不等于整周方案已审核。

完整性按实际课程目的、阶段、适用背景、目标与可编译执行结构判断；删除恢复、缺主训练段或留下占位均不能算完整。测试覆盖全占位青少年草案、部分完成成人草案、完整Tempo阶段顺序/总时长/恢复次数、提前停止、旧快照、疼痛保护和未测距离，不能仅靠七天卡片通过。

浏览器测试和CI不是生理效果或真实iPhone证明；独立教练审核、完整分组周负荷与适龄质量课仍待完成。
