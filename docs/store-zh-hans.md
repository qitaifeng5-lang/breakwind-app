# 破风 · 简体中文商店资料草案

## 商店文案

| 商店字段 | 简体中文 |
| --- | --- |
| 应用名称 | 破风 |
| App Store 副标题 | 中跑训练课表与饮食记录 |
| App Store 关键词 | 田径训练,间歇跑,速度耐力,节奏跑,周计划,运动营养,食物份量 |
| Google Play 简短说明 | 看每组怎么跑、组间怎么休息，按碗或按份记下每一餐。 |
| 建议类别 | App Store「健康健美」；Google Play「健康与健身」 |

**应用描述**

今天跑哪一课，每组跑多远，组间怎么休息？破风把训练安排和饮食记录放在一起，方便跑者在场边和餐桌旁使用。

按专项、个人最好成绩（PB）和训练组选课，浏览间歇、速度耐力和节奏跑。点开一节课，依次查看热身、主训练、休息安排和冷身。在本周计划里逐日看课，加入自己的课表后可以改期，也可以记录完成了多少。

吃完饭，点进早餐、午餐、晚餐或加餐，搜索刚吃的食物。熟米饭可以直接选半碗或一碗，有标注的包装食品可以按盒记录。页面会显示对应的估算份量或包装规格。保存后能看到这餐已记录的能量、蛋白质、碳水化合物和脂肪，下一次还能从「最近吃过」选回来。

## 给审核员的操作说明

以下步骤从首次安装的免费界面开始，无需登录。

1. 打开「训练」，点显示专项和 PB 的「调整」，选「1500m」和「查看课程」。点「按类型浏览」→「间歇」→「500m 稳定间歇」，可看到热身、主训练、休息安排和冷身。点「加入课表」。再次打开这节课，点「查看课表」→「记录完成情况」，选择「部分完成」并保存。可在「本周计划」查看七天安排。
2. 打开「饮食」，点「午餐」一行的加号，搜索「米饭」，选「白米饭（熟）」。在「日常份量」选择「中碗」和「半碗」，点「保存到午餐」。午餐下会显示这条记录及估算份量。点开记录可修改食物与份量。
