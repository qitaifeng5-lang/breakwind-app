# 专项与适龄周期整改记录 · 2026-11-18

基线：`a3562d2a3d0d7b3ab9f5979a92ae32b1285bcdd5`，沿用 PR #13 的 `codex/training-course-library`。

## 复现与修正

新增回归最初四项全部失败：3000m/5000m/越野完整课次检查、5km同项配速校准、已完成质量课的相邻间隔、比赛日期进入周期。修正后这些场景通过。

| 范围 | 修改前 | 修改后 |
|---|---|---|
| 3000m / 5000m | 通用3分钟分段示例，无完整专项周期 | 分别为600m / 1000m同项节奏；按明确选择的基础/进阶/竞技组提供3/4/5次。产品编排，非文献原处方；主量分别1.8/2.4/3km、3/4/5km，小组慢跑休息150/120秒，无大组休息。须已有相近耐受 |
| 越野 | 与道路共用示例 | 3分钟地形节奏，所选组3/4/5次，120秒慢跑；不从平地PB或跨赛道PB生成目标秒数；避开危险坡面 |
| 800m / 1500m成人竞技 | 已有完整主课，但缺少近期负荷和赛历连接 | 保留10×200、分组300、500重复及英里/800双节奏的剂量和来源；同项近期成绩校准读模型，不能把1500m当英里。加入频率/单次负荷核对、比赛窗口和实际反馈 |
| 初高中 | 成人长期周期之外的待编排框架 | 五专项×基础/进阶/竞技×8/12/16周均有独立初中/高中分支；保留所选专项/组别，不复制成人六课双刺激周，也不降为走跑 |
| 周安排 | 未接近期已确认频率 | 保留完整课次和原休息，撤下超出已知频率的课次。低频周减少质量课数量，不缩短恢复。没有完整日志不推定低能力 |
| 已完成质量课 | `completed`使其跳过相邻检查 | 仍占用恢复窗口；明确未完成/取消课次不虚构负荷；比赛事项也参与检查 |
| 比赛日期 | 周期忽略日期，没有比赛期 | 赛前七日固定相对日期，不随俱乐部时段旋转。撤下相邻发展刺激，预留比赛日，赛后恢复等待复盘。不是自动达峰承诺 |
| 反馈调整 | 完成标记/疼痛，缺少量化反馈 | 可选实际用时、0–10主观用力、1–5疲劳；本人报告与设备记录分开。疲劳触发恢复预览，确认才生效，不回写历史或加量 |

## 初高中内容与限制

初高中均支持完整周期浏览、加入日程、完成反馈、未来恢复调整。年级只选择候选内容，**不是发育成熟度测量**；来源未验证下列精确剂量，独立审核仍待完成。

| 专项 | 初中专项节奏课 | 高中专项节奏课 | 目的与界限 |
|---|---|---|---|
| 800m | 4×20秒，120秒慢跑休息 | 6×20秒，同样休息 | 快而放松的协调，不是全力速度耐力或乳酸耐受训练 |
| 1500m | 4×1分钟，120秒慢跑 | 6×1分钟，120秒慢跑 | 受控节奏与动作稳定，不标成测得阈值 |
| 3000m | 3×2分钟，120秒慢跑 | 4×2分钟，120秒慢跑 | 稳定有氧节奏，不以PB虚构VO₂max |
| 5000m | 3×3分钟，120秒慢跑 | 4×3分钟，120秒慢跑 | 长段受控有氧，保留余力 |
| 越野 | 4×1分钟地形节奏，120秒慢跑 | 6×1分钟，同样休息 | 按地形与体感，非固定圈速 |

基础期以分段受控Tempo为主要刺激，专项期**替换**为上述专项课；旁边保留放松技术、轻松有氧和至少三天不安排跑步课，不把所有质量类别塞进一周。比赛期撤下发展课，恢复期仅轻松支持与可取消的技术。训练组影响已有耐受要求及有氧支持，**PB不改变次数**。

这些是技术与受控有氧方向的适龄周期候选，**不是完整覆盖所有初高中高水平运动员的最大速度、速度耐力或赛季峰值处方**。高水平已有教练安排优先，产品不得额外叠加质量课。体育课、其他运动、营养、成熟度及总训练量仍须由本人和现场教练核对。

## 数据与安全边界

- 同项近期成绩用于分段算术参考；旧PB、目标PB、错误专项不代替当前能力。Tempo和越野不由中跑PB推算。
- 稀疏日志保持未知。只有本人填报的近期基线，或明确标注覆盖完整28天的日志，才用于周频率/周量比较。热身、冷身和其他运动未知时，只报告已知下限。
- 热身为轻松跑、动态活动与相应准备；冷身为放慢和整理。不添加固定时间门槛，不伪造实际距离或结束时间。
- 力量支持放在轻松日，复用熟悉的提踵、臀桥、平衡及躯干控制，不自动新增最大重量、跳跃量或声称已核算其负荷；适龄活动需现场指导。
- 持续疼痛、尚未恢复或已有暂停标记继续阻止安排；适龄分支允许加入课表，不能作为独立教练审核或医学许可。
- “继续巩固”不能覆盖原恢复周或赛前窗口。改期仍保留原风险记录。旧计划、原文、完成情况和运动历史没有批量迁移或覆盖。
- 长期计划仍是既有本地体验，不开启支付；免费课程使用同一内容来源。成人800m/1500m基础、进阶**完整长期周期仍未全部编排**，保留免费已完成课次，不伪称全覆盖。

## 验收内容

回归覆盖新手/普通/进阶/竞技、无设备日志但有训练背景、初中与高中五专项、疼痛、疲劳、部分完成、已完成质量课、未来比赛七种星期位置、固定时段、PB变快不加量、错误/目标成绩不校准、同课跨单课/周计划/长期计划参数一致，以及历史快照不变。

浏览器实际流程覆盖网页及原生App使用的离线HTML入口：高中1500m周期→加入日程→部分完成与疲劳→恢复调整；成人5km单课与周计划均读取实际20分钟成绩显示1000m/240秒，不读取浏览档位15分钟。

本地结果：136项单元回归通过；六种视口的282项完整浏览器回归通过。最后接通可选训练量入口后，另跑小屏320、iPhone尺寸390和桌面的15项相关流程，全部通过。ESLint、TypeScript、39个模块语法及入口完整性检查通过。iOS配置保持无定位后台任务；Hermes构建通过。测试数量不能证明训练处方已经独立验证。

**独立教练审核和真实iPhone运行未完成**。浏览器中的iOS离线入口只证明打包页面与网页流程一致，不等同签名安装或真机验收。本轮不正式发布。
