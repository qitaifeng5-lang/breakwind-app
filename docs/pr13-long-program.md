# PR13 · 长期训练与VIP体验边界

对应规格6778391423。沿用正式训练页、四段式课程、私有课表、日程和记录。没有接入真实支付、启用自动续费、购买服务或更改仓库可见性。

## 实际可操作流程

训练页「长期训练 · 体验」→复用已有专项/PB，选择8/12/16周及开始日期→预览所有周与完整课程→启用明确标记的本地体验→保存周期→安排一周。已有固定时段和教练安排优先；时间容不下完整热身、主课、恢复、冷身及缓冲时不安排，缺同项成绩不猜耗时。开始已有周期课次复用原计划ID，不能重复建课。

阶段复盘区分已安排、真实关联完成、取消及过期未完成；推进需要确认，不按日历或续费跳周。调整先预览：根据实际关联记录和恢复状态建议保持熟悉结构或下一周恢复，确认才更新未来。旧计划快照保留为取消；完成历史、教练课不改写。漏课不自动补堆，PB更新不增加组数或缩短恢复。暂停后不得重新启动该周期课次，恢复仍受已有伤痛与疲劳检查约束。

日期按保存的民用时区/日期处理，跨夏令时不通过UTC秒数加周。当前时区不同需确认未来时区，既有课次不自动平移。此版本尚不提供跨时区航班/旅行日程自动换算。

## 内容范围与依据

已贯通800m、1500m成人竞技均衡型的8/12/16周候选。来源、组别、阶段、目标、分段、全部恢复及原审核状态由既有完整课程继承；没有将基础组标题换成竞技。基础确认→同项间歇衔接→恢复→专项发展→巩固/对比刺激→复盘有固定顺序；巩固周有意维持熟悉剂量，不每周随机换课或加量。阶段转换仍要核对既有耐受和恢复。

[Haugen等2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8363530/)支持中跑个体差异、周期化和恢复原则，不验证本产品的逐周排列。各课公开实践来源见正式详情；8/12/16长度、恢复周位置、顺序和成年俱乐部适用条件属于产品编排，尚无独立教练审核或实际训练效果验证。私人教练原文未进入公共模板。

完整覆盖与缺口见`pr13-program-coverage.md`。其他专项、基础/进阶长期周期和青少年竞技长期方案尚未完成，不声称VIP支持。现有免费完整单课与基础周保留；未充分核验的旧教学候选不能被“会员”变成已审核计划。本轮不声称全部专项的课程质量已达标。没有比赛日期要求；自动比赛日倒排和完整比赛赛季安排尚未接通。

## 会员只在本地体验

产品目标ID：`breakwind_vip_monthly`；目标币种CNY，金额整数1290分，目标月费¥12.90。尚未核验真实渠道价格点，不是正式售价承诺。无年费、终身、首月促销或年度承诺月付。

当前仓库没有账户绑定或可信支付服务端。`membership.js`只处理明确标记的experience测试事件；生产权限判断拒绝任何本地VIP状态，即使伪造verified字段也不放行。模拟重复事件/较旧顺序事件不改变新状态；待确认、取消、失败、续费、取消续费、到期、撤销及从当前模拟渠道状态恢复分别处理。恢复旧购买记录不能覆盖撤销状态。本地体验有效期测试使用30天，不能当作商店月度计费规则或恢复真实购买的证明。

到期停止新周期保存和会员未来调整；已经生成的周期、免费手动安排、历史与个人导出仍可用。已有分段计时与保存不读取会员状态。续费只更新体验权益，不重置训练进度。模拟数据仅在此浏览器，恢复购买是模拟渠道状态测试，不是跨设备真实购买恢复。

正式接入前仍需账户/服务端权益、可信交易验证、幂等渠道通知及真实商店沙盒验收。Apple使用StoreKit/App Store Connect；Android发行渠道尚未选定，不能假设全部采用Google Play。已查阅[Apple订阅](https://developer.apple.com/app-store/subscriptions/)与[Google Play生命周期](https://developer.android.com/google/play/billing/lifecycle/subscriptions)；Google官方要求服务端查询权威订阅状态，本地模拟未实现该生产能力。真实渠道价格、签名、税务/协议和费用需本人另行确认。

## 验收口径

测试检查逐周具体课程/总量/恢复、同组与阶段关系、PB不改变剂量、教练锁定、改时无重复、取消不重建、实际完成关联、未来调整不可回写历史、时区/夏令时/跨月、到期和重启保存、模拟通知顺序。浏览器实际操作周期预览→保存→安排→调整→推进→到期→导出，以及计时中到期→重启→完成保存。

浏览器移动视口及加速运动时钟不是实际跑步。未做真实iPhone验收、独立教练审核、StoreKit/安卓真实支付沙盒验证。现阶段不可按“已获专业认证或支付已上线”对外销售。
