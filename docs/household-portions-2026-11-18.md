# 饮食日常份量 · 2026-11-18

基线：PR #13 `8bbdad1f29c767ed5b0b6afcdf6e0504e51593bd`。本次修改正式份量选择和记录链路，不涉及训练处方。

## 用户操作

有日常份量的食物，默认先选碗、份、个、根、片、杯或包装单位，再选半份、1、1.5、2或直接输入数量。常用三个单位先展示，其他放在“更多单位”。“按克输入／按毫升输入”保留为单次切换。份量下方显示本次换算量；估算显示“约”，具体份量来源可展开。

食物记录、最近吃过、餐食详情和组合使用相同的份量文案。每项餐食保存所选单位、数量、当时的换算量和来源，而不只保存食品库引用。编辑旧记录使用旧营养及份量快照；切到克／毫升输入后清除日常单位。复制昨日、组合、离线保存保留快照。相同食物的最近记录按日期、录入时间和录入顺序取最后一次。编辑复制记录保留 copiedFrom，防止再次复制重复。

## 数据边界

- 已有 USDA 食物份量继续使用其原始克／毫升基准。2片对应的总重先归一为每片，半杯等分数同样处理。
- 日常熟米饭碗、沥水熟面碗、成品粥碗、部分菜品和现有配方的份，是破风明确标识的编辑估算。小中大按具体食物定义，不是所有碗统一克重，也不是薄荷数据。
- 源 cup 仍是来源量杯；不能直接换名称为碗。生米与熟饭、干面与熟面、口味零食与食物本体不混用。
- 个／根按来源可食部分；盒／袋／瓶只取相应商品实际已收录的标签份量。g 与 mL 不互相冒充；未知营养项继续是 null。
- 无可靠单位且无上述明确估算的条目，保留精确输入，不虚构“一份100克”。当前功能不等于完整中国市场食品与份量库。
