# 破风 BREAKWIND

手机优先的简体中文跑步训练 Web App。项目包含训练仪表盘、跑步计时与手动日志、日历、恢复、营养、个人纪录、知识库和七日基础训练引擎。

## 本地启动

需要 Node.js 22 或更高版本，无第三方依赖。

```sh
npm start
npm test
```

启动后访问 http://127.0.0.1:4173 。首页右上角可进入只读演示。个人记录保存在当前浏览器的本地存储。使用同一地址和浏览器可继续访问已有记录。支持的浏览器可在首次加载并完成缓存后离线打开应用。

## 训练引擎

打开「学院 → 生成训练草案」，选择训练基础并预览。引擎使用实际跑步记录、近三日恢复、训练目标和已有日程。确认前不修改日历，确认时会重新检查草案。保存后的训练可以在日历中编辑。规则与证据条目位于 public/engine.js。

此版本覆盖七日基础训练。目标成绩用于记录，专项配速、长周期课表、生成式教练、图片营养识别、原生传感器和跨设备同步尚待实现。
